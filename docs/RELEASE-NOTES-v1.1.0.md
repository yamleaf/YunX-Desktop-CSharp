# YunX Desktop v1.1.0

**Windows 高速下载器 · C# / WPF 重构版**

相比 v1.0.0，这一版把「收藏」从摆设做成了真功能、统一了全部弹窗的外观、
补齐了设置页的交互细节，并修掉了几处会直接影响使用的问题。

`Windows 10/11 x64` · 单文件 71 MB · 无需安装 .NET · AGPL-3.0

| 文件 | 说明 |

## v1.1.0 新增了什么

### 收藏：从"只能存"变成完整功能

v1.0 的收藏更像个半成品 —— 有个按钮能点，但看不到收藏了什么。
这一版补齐了整条链路：

- **独立收藏页**：侧边栏新增入口（带数量徽标），列表带「载入 / 重命名 / 删除」，
  支持「清空全部」，空态有引导
- **自定义命名**：给收藏起中文名（如「Rust 语言」），起过名的显示自定义名、
  带「自定义」小标记；没起名的显示网址。**重新收藏同一链接不会覆盖你起的名字**
- **点一下直达**：从侧边栏点收藏 → 自动切回解析页 + 自动开始解析，
  不用再手动点一次「解析」

### 弹窗：统一为自绘外壳

v1.0 的弹窗用系统标题栏，在深色界面里是白色的一条，而且**打开时会先闪一下白框**。
v1.1 全部改为自绘（与主窗口一致）：

- **圆角 + 深色标题栏 + 红色关闭按钮**，视觉与主界面统一
- 标题栏可直接拖动窗口
- **彻底消除闪白**：整个窗口由 WPF 绘制，不再有"系统先填白"的那一层
- 覆盖范围：输入框、确认框、选择框、内嵌浏览器登录窗

### 设置页

- **勾选框全部换成滑动开关**（12 处）：iOS 风格胶囊开关，整行可点，
  不必精确点到那个小开关上
- **按钮对齐修正**：保存设置、导出诊断日志、重置为默认值统一到右下角
  （Windows 惯例里主操作在右下，左下是"返回/取消"的位置）

### 交互细节

- **资产列表底部加操作栏**：文件列表很长时，勾完选不用再滑回顶部点「开始下载」，
  底部直接有按钮，还会实时显示「已选 28 / 30 个文件」
- **收藏区可折叠**：侧边栏收藏多了可以收起来，状态会记住
- **深色 ToolTip**：v1.0 全项目的提示框都是系统白底，在深色界面上很刺眼

## v1.1.0 修了什么

### 解析历史不再重复

v1.0 的去重窗口只有 1 小时，且按原始字符串比对。结果同一个仓库隔两小时再解析一次，
历史里就多一条一模一样的记录。

现在：

- **同链接永远只有一条**，再次解析只更新时间
- **链接规范化**：带不带协议、末尾有无斜杠、有没有 `www` 都算同一个
  （`/releases` 和仓库根路径仍算不同，不会误合并）
- **老数据自动清理**：启动时按规范化 key 去重，每组只留最新一条

### 其他修复

- 收藏页点击后不刷新，要重启才能看到新记录
- 「清空收藏」确认框出现三个按钮（清空 / 取消 / 取消）
- 点「清空全部」报错 `无法将 Owner 属性设置为它本身`
- 对话框跑到屏幕左上角而不是居中
- 收藏标题被存成「等待输入链接」这个输入框占位提示

## v1.0.0 已有的能力（未变）

### 下载引擎

- **多镜像择优**：内置 GitHub 加速线路，启动时测速排序，失败自动切换并冷却
- **分块多线程**：块数反算 + 尾部收缩，避免尾块碎片（原版实测出现过 **15 字节**的尾块）
- **慢连接抢占**：看门狗按"在飞分片速度中位数"判定掉队，连续两次采样才抢
- **断点续传**：`ETag` / `Last-Modified` 校验，内容变了不会拼出损坏文件
- **分片哨兵校验**：抽查首尾摘要，能抓住 `pwrite` 偏移写错这类静默损坏
- 可选全文件 SHA-256、限速、Range 降级容忍、无锁并发写

### 支持的来源

| 类型 | 支持 |
|---|---|
| **GitHub** | 仓库 / 单文件 / 目录 / Release（资产多选）/ 归档 / gist / `owner/repo` 简写 |
| **仓库浏览** | 逐层进入目录、点文件直接入队 |
| **README 预览** | GFM 渲染：标题 / 代码 / 列表 / 引用 / 表格 / 行内格式，相对图片自动改写为 raw 地址 |
| **磁力** | `magnet:` 链接 → 自动下载安装 Gopeed 内核 → 子进程负责 DHT/tracker/peer 调度 |
| **网盘（10 个）** | 夸克 / UC / 迅雷 / 百度 / 139 / 123 / 115 / 蓝奏 / 光鸭 / 星海口令 |

### 任务与数据

- 暂停 / 继续 / 取消 / 删除，排队并发控制
- **持久化与重启恢复**：入队即写库，进度按 5 秒节流写盘，
  下载中强杀或断电，重启后任务与进度都还在
- 已完成任务保留为下载历史（默认最近 100 条）
- 完成通知、系统托盘

### 安全

- 网盘 Cookie 与 GitHub Token 均 **AES-256-GCM 加密落盘**（信封加密）
- 主密钥三档保护：明文 / **机器绑定（默认）** / DPAPI 用户绑定
- **认证备份**：用口令派生密钥导出 `.yunx`，可在任意设备恢复

### 网络

- **DoH 绕过 hosts 劫持**：检测到 `github.com` 被指向 `127.0.0.1` 时自动解析真实 IP
- 直连 / 系统代理自动探测、可选 HTTP/2

## 已知限制

**这些不是 bug，是客观约束**，都已在界面上给出明确提示而非静默失败：

- **仓库 zip 走单流**：`codeload` 不支持 Range，GitHub 服务端动态打包所致
- **慢连接抢占需 ≥15 秒**才能判定 —— 太早会把正常爬坡的连接误杀
- **镜像可用性随地区/时间变化**，可在设置里调整线路
- **10 个网盘的网络层未经真实账号验证**：逻辑层（链接解析 / 签名 / 错误码 / 加密）有断言覆盖，
  但"能构造正确请求"不等于"能拿到直链"，需要你用自己的账号实测
- **自动更新已移除**：原实现比对的是上游 Kotlin 项目的 Release tag，
  与本版没有可比性，会误导用户去装另一个程序
- **换电脑后登录态失效是设计**：凭证等价于账号控制权，不应拷个数据目录就能在别处使用
