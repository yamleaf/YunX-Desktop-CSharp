# YunX Desktop v1.0.0

**Windows 高速下载器 · C# / WPF 重构版**

把 [YunX-Desktop](https://github.com/tidain/YunX-Desktop)（Kotlin + Compose Desktop）的核心链路
用 C# / .NET 8 / WPF 重写。不是逐行翻译 —— 下载引擎按实测数据重做了几处关键设计，
并补上了原版没有的能力。

`Windows 10/11 x64` · 单文件 71 MB · 无需安装 .NET · AGPL-3.0

## 这个版本有什么

### 下载引擎

- **多镜像择优**：内置 GitHub 加速线路，启动时测速排序，失败自动切换并冷却
- **分块多线程**：块数反算 + 尾部收缩，避免尾块碎片（原版实测出现过 **15 字节**的尾块）
- **慢连接抢占**：看门狗按"在飞分片速度中位数"判定掉队，连续两次采样才抢 —— 抢的是连接，不是判失败
- **断点续传**：`ETag` / `Last-Modified` 校验，内容变了不会拼出损坏文件；单流（如仓库 zip）也能续传
- **分片哨兵校验**：抽查首尾摘要，能抓住 `pwrite` 偏移写错这类"长度对但内容错"的静默损坏
- **可选全文件 SHA-256**
- 限速、Range 降级容忍、无锁并发写

### 支持的来源

| 类型 | 支持 |
|---|---|
| **GitHub** | 仓库 / 单文件 / 目录 / Release（资产多选）/ 归档 / gist / `owner/repo` 简写 |
| **仓库浏览** | 逐层进入目录、点文件直接入队 |
| **README 预览** | GFM 渲染：标题 / 代码 / 列表 / 引用 / 表格 / 行内格式，相对图片自动改写为 raw 地址 |
| **磁力** | `magnet:` 链接 → 自动下载安装 Gopeed 内核（约 38 MB，走镜像加速）→ 子进程负责 DHT/tracker/peer 调度 |
| **网盘（10 个）** | 夸克 / UC / 迅雷 / 百度 / 139 / 123 / 115 / 蓝奏 / 光鸭 / 星海口令 |

### 任务与数据

- 暂停 / 继续 / 取消 / 删除，排队并发控制
- **持久化与重启恢复**：连请求头、网盘上下文、断点路径一起存，重启后可续
  - 入队即写库 —— 下载中强杀或断电，重启后任务与进度都还在
  - 进度按 5 秒节流写盘，状态变化（暂停/完成/失败）立即写
  - **已完成任务保留为下载历史**，默认最近 100 条（设置里可调），重启后仍能看到下过什么
- 解析历史、链接收藏、完成通知、系统托盘

### 安全

- 网盘 Cookie 与 GitHub Token 均 **AES-256-GCM 加密落盘**（信封加密）
- 主密钥三档保护：明文 / **机器绑定（默认）** / DPAPI 用户绑定
- **认证备份**：用口令派生密钥导出 `.yunx`，可在任意设备恢复（换电脑的正路）

### 网络

- **DoH 绕过 hosts 劫持**：检测到 `github.com` 被指向 `127.0.0.1` 时自动解析真实 IP
- 直连 / 系统代理自动探测
- 可选 HTTP/2

## 已知限制

**这些不是 bug，是客观约束**，都已在界面上给出明确提示而非静默失败：

- **仓库 zip 走单流**：`codeload` 不支持 Range，GitHub 服务端动态打包所致
- **慢连接抢占需 ≥15 秒**才能判定 —— 太早会把正常爬坡的连接误杀
- **镜像可用性随地区/时间变化**，可在设置里调整线路
- **10 个网盘的网络层未经真实账号验证**：逻辑层（链接解析 / 签名 / 错误码 / 加密）有断言覆盖，
  但"能构造正确请求"不等于"能拿到直链"，需要你用自己的账号实测
- **自动更新已移除**：原实现比对的是上游 Kotlin 项目的 Release tag，
  与本版（版本号从 1.0.0 起算）没有可比性，会误导用户去装另一个程序
- **换电脑后登录态失效是设计**：凭证等价于账号控制权，不应拷个数据目录就能在别处使用。
  跨设备请用「账号 → 认证备份」导出 `.yunx`

## 验证情况

| 项 | 结果 |
|---|---|
| 编译 | 0 警告 0 错误 |
| 离线断言 | **258 项全通过**（含下载引擎端到端） |
| 真实网络实测 | 磁力全链路：内核下载 38.5 MB → 引擎启动 → 建任务 → 状态 running → 删除，通过 |

下载引擎端到端用本地裸 `TcpListener` 伪造 HTTP 服务，不连外网，覆盖：
分片并发的 206 请求与内容哈希、自定义请求头透传、Range 被忽略后的整任务降级、
直链随即 403 的**有界失败**、取消保留断点、预置半个 part 的续传。
